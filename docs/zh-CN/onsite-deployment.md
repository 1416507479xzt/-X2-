# 赛方统一 X2 的现场部署要点

完整可复制的电脑构建、SSH 部署、机器人终端联调与验收步骤见[从新电脑复现 X2 自研语音 Agent](reproduce-on-x2.md)。本页记录比赛现场相对手头机器人新增的不确定项。

参赛手册要求在赛方提供的灵犀 X2 真机上部署和演示，并提前准备最终代码、配置文件与调试文件；具体安排以组委会后续通知为准。赛方机器的固件、AimDK 版本、Python 环境、账号和网络策略尚未确认。

**手册没有明确授权或禁止把程序复制到赛方机器人 PC2。**当前 ZIP + SSH/SCP 方案以赛方允许文件传输和 PC2 上运行二开程序为前提；不能把手头 X2 的权限推定到赛方机器。

## 部署权限确认后的路径

| 赛方允许的方式 | 当前项目状态 | 需要准备 |
|---|---|---|
| 允许向 PC2 传文件并运行 | 已有离线 ZIP、预检和真机启动入口 | 现场版本匹配、传输方式、`only_voice` 切换与恢复、云端网络须确认 |
| 不允许复制到 PC2，但允许外部上位机跨机 ROS 组网 | 官方 AimDK 提供上位机方案；当前项目尚未按外部主机完整构建和测试 | Ubuntu 22.04、ROS 2 Humble、对应固件的 SDK、有线直连、外部主机依赖包及端到端验证；现有 aarch64 ZIP 不能直接在 x86_64 上运行 |
| 两种方式都不允许 | 当前自研语音 Agent 无法按既定方案接入赛方机器人 | 需组委会提供其他正式部署通道，不能把仿真运行或录播当成现场真机接入 |

上位机要求以[灵犀 X2 官方开发环境说明](https://x2-aimdk.agibot.com/zh-cn/latest/quick_start/prerequisites.html)和赛方现场配置为准。先向组委会确认：PC2 文件传输/运行权限及方式、是否提供开发容器或预装通道、机器人固件与 AimDK 版本、是否允许外部 Ubuntu 上位机有线接入、是否允许切换/恢复 `only_voice`、云服务网络及现场调试时长。

## 到场先核对

1. 确认机型是否为 X2 Ultra，以及赛方允许的 SSH、文件复制、原生交互模式切换和恢复方式。官方 [`only_voice` 过渡方案](https://x2-aimdk.agibot.com/zh-cn/latest/faq/temp_works.html)明确限定 X2 Ultra。
   手头 X2 的 PC2 `aima em` 应用列表没有 `agent`，官方示例里的重启命令不能在该 PC2 直接复用；需先确认交互模块所在计算单元及实际重启方式。
2. 在 PC2 上只读检查 `uname -m`、`python3 --version`、机载 AimDK `version` 文件和 `ros2 interface`；再运行包内 `scripts/robot_preflight.py`。已知离线包只针对 Linux aarch64、CPython 3.10 和 AimDK v1.0.0/v1.1.0 的音频接口。其他版本先适配再演示。
3. 确认机器人运行时能连接豆包语音和火山方舟服务，并获准使用自备 API Key。离线包免去真机上下载 Python 依赖，不能替代云端服务网络。
4. 先做只读 PCM 和 ASR 转写，再按官方流程切换与恢复 `only_voice`，依次测模型回答、TTS 音频焦点、表情动作及环节一、二、四的连续对话。每一项均需保存不含密钥和真实长者隐私的结果。

当前手头 X2 的 VAD PCM 输入和一次豆包语音 ASR 转写已完成真机实测。省赛机器上是否能零修改运行，取决于上述现场接口与环境核对结果；未通过预检时不要绕过检查启动完整 Agent。
